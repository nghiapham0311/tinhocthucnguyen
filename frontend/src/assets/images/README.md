# Ảnh của website

Bỏ file ảnh vào thư mục này với đúng tên bên dưới (đuôi `.png`, `.jpg`, `.jpeg`, `.webp` hoặc `.svg` đều được).
Chưa có file thì trang hiện khung sọc ghi tên file cần bổ sung.

| Tên file (không đuôi) | Dùng cho |
|---|---|
| `logo` | Logo nền sáng (header) |
| `logo-white` | Logo chữ trắng (footer, header trang Chứng chỉ) |
| `poster-chieu-sinh` | Poster chiêu sinh tháng 12 |
| `lop-hoc-thuc-hanh` | Học viên thực hành tại lớp |
| `phong-may` | Toàn cảnh phòng máy |
| `lop-hoc-1` | Lớp học với máy tính |
| `lop-hoc-2` | Sinh viên / lớp học buổi tối |
| `be-hoc-may-tinh` | Bé học máy tính (trang Khóa học) |
| `chung-chi-co-ban` | Chứng chỉ Ứng dụng CNTT cơ bản |
| `chung-chi-nang-cao` | Chứng chỉ Ứng dụng CNTT nâng cao |
| `icon-chuot`, `icon-ban-phim`, `icon-may-tinh` | Biểu tượng 256×256 (trang Thiếu nhi) |
| `icon-word`, `icon-excel`, `icon-powerpoint` | Biểu tượng 256×256 |

Danh sách đầy đủ nằm trong `src/images.js`.
